## 1. プロジェクト概要

### 1.1 目的
**「現在使用している管理アプリの使いづらさを解消し、自分にとって最高の使い勝手を実現する」**

### 1.2 ターゲットユーザー
* **個人ユーザー**（自分自身のトレーニング管理を効率化したい方）

### 1.3 主な機能
* **筋トレ記録:** 部位・種目・重量・回数の登録
* **有酸素運動記録:** 運動種目・時間・距離の管理
* **カレンダー表示:** 過去の実施日を一覧で確認（Google Calendar APIを使用してGoogleカレンダーと連携）
* **グラフ表示:** トレーニング強度の推移を可視化

---

## 2. システム要件

### 2.1 機能要件

| No | 機能名 | 説明 | 優先度 |
| :--- | :--- | :--- | :--- |
| 1 | 筋トレ記録 | 種目、重量、回数、セット数を入力し保存する | 高 |
| 2 | 有酸素運動記録 | 種目（ランニング等）、時間、距離を入力し保存する | 高 |
| 3 | カレンダー表示 | 記録がある日をカレンダー上で可視化し、選択すると詳細を表示する | 中 |
| 4 | グラフ表示 | 種目ごとの最大重量の推移をラインチャートで表示する | 低 |
| 5 | マイページ | ユーザーのプロフィール編集や目標設定を行う | 中 |
| 6 | タイムライン | 他ユーザーの筋トレ投稿を表示する　| 低(追加予定) |
| 7 | いいね機能 | 刺激を受けた機能にリアクションする　| 低(追加予定) |

### 2.2 非機能要件 
* **性能:** ジムの不安定な通信環境でもストレスなく利用できるよう、表示速度の高速化を図る(SPAの使用)
* **セキュリティ:** パスワードはハッシュ化して保存し、万が一の流出時も解読不能な状態にする
* **ユーザビリティ:** スマホを片手トレーニングすることを想定し、PC画面とモバイル画面のどちらも設計する
* **保守性:** コードの書き方を統一し読みやすく保つ

## 3.　技術スタック 


### 3.1 開発環境
* **言語:** C#13 / TypeScript 5x
* **フレームワーク:** ASP.NET Core 9.0 / React 18.x
* **IDE:** Visual Studio Code
* **バージョン管理:** Git＋Github

### 3.2 使用ライブラリ・パッケージ
| パッケージ名 | 用途 | バージョン | 
| :--- | :--- | :--- | 
| Entity Framework Core | C#からSQLを書かずにDB操作を行う（ORM）| 8.x |
